# Design system

- **Figma:** https://www.figma.com/design/GU5UnfHbU6euTRmiU0xMQz/Portfolio_app
- **Pages:** Desktop, Tablet, Mobile, Components.
- **Canvases:** Desktop 1440×1024, Tablet 768×1024, Mobile 390×844.
- **CSS ranges:** mobile < 600, tablet 600–1279, desktop ≥ 1280.
- **Tokens:** `Colors` variable collection, names mirror `src/styles/_variables.scss`. Light mode only until dark mode (#6).

## Components

- `Button` — Primary / Outline, `Label`.
- `Social Link` — `Icon` swap.
- `Skill Card` — `Icon` swap, `Name`.
- `Contact Card` — `Icon` swap, `Label`, `Value`.
- `Input` — Input / Textarea, `Placeholder`.
- Icons: `icon/*`, `skill/*`.
